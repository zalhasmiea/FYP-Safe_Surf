## Installation Guide

Follow the steps below to run the system.

### 1. Start the Backend

1. Open the project folder.
2. Navigate to the **backend** folder.
3. Run the main.py

This will start the backend server required for the extension.

---

### 2. Load the Browser Extension

1. Open Google Chrome.
2. Go to:
chrome://extensions/

3. Enable Developer Mode (top right corner).
4. Click Load unpacked.
5. Select the extension folder from this project.

### 3. Using the Extension

Once installed, the extension will start communicating with the backend server to analyze URLs for phishing detection.
Make sure the backend server is running before using the extension.
